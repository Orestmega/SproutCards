# Як перевірити застосунок на iPhone

Цей файл для власника. **Нічого не опубліковано і нічого не зроблено без вашої згоди**: усі дії нижче
виконуєте ви. Симулятора iPhone на Windows немає, а service worker (офлайн, встановлення) працює лише за
**захищеною адресою https**, тому для перевірки сайт треба один раз викласти в інтернет.

Чому не підійде «відкрити з комп'ютера по Wi-Fi» (`http://192.168...`): без https Safari не запускає
service worker, і офлайн-режим та встановлення перевірити не вдасться. Сам інтерфейс так подивитись можна,
але це не те, що ви хочете знати.

## Крок 0. Що вже готово в проєкті

- Збірка: `npm run build` створює теку `dist/` (це і є весь сайт, лише статичні файли).
- Конфігурація для хостингів: `public/_headers` (заголовки безпеки й кешування для Cloudflare Pages і
  Netlify), `.github/workflows/deploy-pages.yml` (публікація на GitHub Pages; запускається **автоматично після кожного push у main** і вручну
  після того, як ввімкнено Pages у налаштуваннях репозиторію), `public/.nojekyll`.
- Шляхи в збірці відносні, тому сайт працює і з кореня домену, і з підпапки (`user.github.io/sproutcards/`).

## Крок 1. Оберіть, де викласти сайт (безкоштовні варіанти)

Умови безкоштовних планів змінюються: перед вибором прочитайте актуальні на сайті сервісу. Нижче: те, що
важливо для цього проєкту, без цін і лімітів.

| Варіант | Плюси | Мінуси |
|---|---|---|
| **GitHub Pages** | Репозиторій і хостинг в одному місці; готовий workflow; адреса `https://<імʼя>.github.io/<репозиторій>/` | Потрібен GitHub-акаунт і `git push` (це окреме ваше рішення, див. «Чергу рішень власника»). Безкоштовний план публікує з **публічних** репозиторіїв. Не вміє власні заголовки, тож `_headers` (CSP) не діє |
| **Cloudflare Pages** | Підтримує `_headers`; можна завантажити теку `dist` без Git (Direct Upload); швидка мережа | Потрібен акаунт Cloudflare |
| **Netlify** | Найпростіше: перетягнути теку `dist` у вікно на сайті (Drop), підтримує `_headers` | Потрібен акаунт; безкоштовний план має ліміти (перевірте актуальні) |
| **Vercel** | Зручна інтеграція з Git | Потрібен акаунт; заголовки там задаються іншим файлом (`vercel.json`), якого в проєкті немає; безкоштовний план призначений для некомерційного використання |

**Рекомендація:** для першої перевірки на iPhone — **Netlify Drop або Cloudflare Pages (Direct Upload)**:
не потрібен ні Git, ні push, ні публічний репозиторій, а нашу `_headers` буде застосовано. Для постійного
сайту — GitHub Pages, коли ви вирішите, що код має бути публічним. **Варіант за замовчуванням:** нічого не
публікувати, доки ви не підтвердите (ви ще не відповіли на пункти про хостинг і GitHub).

## Крок 2. Опублікуйте (приклад: Netlify Drop)

1. На комп'ютері: `npm ci`, потім `npm run build`.
2. Відкрийте сторінку Netlify Drop (у вашому акаунті Netlify) і перетягніть у неї **теку `dist`** (саму
   теку, а не файл усередині).
3. Скопіюйте адресу виду `https://щось.netlify.app`. Відкрийте її на комп'ютері й переконайтесь, що
   сайт працює.

Для Cloudflare Pages: створіть проєкт типу «Direct Upload» і завантажте ту ж теку `dist`.
Для GitHub Pages: у репозиторії Settings → Pages → Source: «GitHub Actions», потім вкладка Actions →
«Deploy to GitHub Pages» (запускається сам після кожного push у main; за потреби Run workflow).

## Крок 3. Встановіть на iPhone

1. Відкрийте адресу **у Safari** (не в Chrome для iOS і не у вбудованому браузері месенджера).
2. Зачекайте, поки сторінка повністю завантажиться, поки зник індикатор. Потім оновіть сторінку один раз.
   Це потрібно, щоб service worker «підхопив» сторінку. У застосунку: Налаштування → «Застосунок на цьому
   пристрої» має написати «Офлайн-режим увімкнено».
3. Натисніть «Поділитися» (квадрат зі стрілкою) → **«На початковий екран»** → «Додати».
4. Закрийте Safari й відкрийте застосунок **зі значка на домашньому екрані**.

> **Важливо:** на iPhone застосунок із домашнього екрана має **власне сховище, окреме від Safari**.
> Колоди, створені у вкладці Safari, у встановленому застосунку не з'являться. Спершу встановіть, потім
> вчіться. Якщо вже щось створили у Safari: «Налаштування → Резервна копія та імпорт» → завантажити копію
> там, імпортувати у встановленому застосунку.

## Крок 4. Перелік перевірок

Позначайте результат прямо тут або в `JOURNAL.md` (розділ «Не перевірено на пристрої» → переносьте
пункти, які пройшли). Кожен пункт: ✔ працює / ✘ не працює (що саме) / — не перевірялось.

| № | Що зробити | Очікування |
|---|---|---|
| 1 | Відкрити сайт у Safari | Інтерфейс на повну ширину, нічого не обрізано, нижня навігація не під «чубчиком»/смугою Home |
| 2 | Додати на початковий екран і відкрити зі значка | Відкривається без адресного рядка; значок із паростком, не чорний квадрат |
| 3 | Налаштування → «Застосунок на цьому пристрої» | Написано «Встановлено…» і «Офлайн-режим увімкнено» |
| 4 | Каталог колод → додати «Подорожі» | Колода з'являється, показується «Не перевірено» біля карток |
| 5 | Увімкнути **авіарежим**, повністю закрити застосунок (змахнути з перемикача програм), відкрити знову | Застосунок відкривається, колода на місці |
| 6 | В авіарежимі пройти «Вчити», «Картки», «Тест» | Усе працює; після завершення результати зберігаються |
| 7 | Озвучка (кнопка з динаміком) | Слово читається. Якщо ні: перевірте гучність; голос для української додається в Налаштування iOS → «Універсальний доступ» → «Мовлення» → «Голоси» |
| 8 | Ввести відповідь з клавіатури iPhone | Клавіатура не закриває поле й кнопки; регістр і апостроф не заважають перевірці |
| 9 | Налаштування → Резервна копія → «Завантажити копію» | Файл зберігається («Файли» / «Завантаження»); імпорт цього файлу працює |
| 10 | Закрити застосунок на кілька днів, відкрити | Колоди й прогрес на місці. Якщо зникли: запишіть, через скільки днів |
| 11 | Мова інтерфейсу: перемкнути українська ↔ англійська | Усі тексти змінюються, нічого не лишається іншою мовою |
| 12 | Оновлення: опублікувати нову збірку, відкрити застосунок | З'являється «Готова нова версія»; після «Оновити зараз» колоди на місці |

Що чекати від iOS: число на значку (повторення на сьогодні) у Safari-PWA може не працювати. Сповіщень застосунок
не надсилає взагалі (так задумано, див. `docs/HOW_IT_WORKS.md`).

## Якщо щось не працює

- **Не пропонує «Додати на початковий екран»:** ви не в Safari або сайт відкрито у вбудованому браузері.
- **Офлайн-режим не вмикається:** адреса має бути https; після першого завантаження оновіть сторінку ще раз.
- **Порожній екран:** закрийте застосунок і відкрийте знову; якщо лишилось, видаліть значок і додайте заново
  (дані встановленого застосунку при цьому видаляються, тож спершу зробіть резервну копію).
- Запишіть модель iPhone, версію iOS і що саме сталось, і передайте мені: виправлю.

## Після перевірки

Тест не залишає на пристрої нічого, окрім самого застосунку. Щоб прибрати: притримайте значок → «Видалити
програму». Вимкніть публікацію на хостингу, якщо вона вам більше не потрібна.
