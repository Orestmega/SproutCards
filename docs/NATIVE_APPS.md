# Додатки для Android та iPhone

Це той самий код, що й сайт, загорнутий в оболонку [Capacitor](https://capacitorjs.com). Сайт (PWA) нікуди не
ділось: він і далі публікується окремо. Додаток для телефона збирається з тієї ж збірки (`dist/`), тому
будь-яка зміна в застосунку потрапляє і в сайт, і в додаток.

- Назва програми: **SproutCards**, ідентифікатор `app.sproutcards.mobile` (після публікації в магазині його
  змінити не можна; для себе й друзів неважливо).
- Дані (колоди, прогрес) лежать **на телефоні**, у базі додатка, і працюють без інтернету. Сайт і додаток мають
  **окремі** сховища: колоди з сайту в додатку не з'являться, переносіть їх резервною копією (файл).
- Служби сайту (service worker, «Встановити») в додатку **вимкнено**: файли і так усередині. У Налаштуваннях
  додатка замість них короткий опис.

## Android: як отримати файл `.apk` (нічого ставити на ПК не треба)

Збірку робить GitHub на своєму сервері. Потрібен лише ваш акаунт GitHub, на якому лежить репозиторій.

1. Репозиторій → вкладка **Actions** → зліва **«Build Android app»** → **Run workflow** → зелена кнопка.
2. Чекайте приблизно 5–10 хвилин (перший запуск довший). Біля запуску має бути зелена галочка.
   Якщо червоний хрестик, скопіюйте мені текст помилки.
3. Відкрийте цей запуск, внизу в розділі **Artifacts** натисніть **sproutcards-android-apk**. Скачається zip із
   файлом `app-debug.apk`. Це можна робити просто з телефона (в браузері, увійшовши в GitHub).
4. На Android: відкрийте `app-debug.apk` (із «Завантажень»). Телефон скаже, що встановлення з цього джерела
   заборонено. Натисніть **«Налаштування»** і **дозвольте для цього браузера/файлового менеджера**, потім
   поверніться й натисніть «Встановити». Google Play Protect може попередити про «невідомого розробника»: це
   нормально для додатка, який не з магазину («Все одно встановити»).
5. Відкрийте SproutCards зі значка.

### Важливо: оновлення
Це збірка для налагодження (debug). GitHub підписує її **новим ключем кожного разу**, тому Android вважає
кожну нову збірку іншим застосунком і **не дає встановити її поверх старої**. Щоб оновитись:
1. У старому додатку: Налаштування → Резервна копія та імпорт → «Завантажити копію» (оберіть, куди зберегти).
2. Видаліть старий додаток, встановіть новий `.apk`.
3. Імпортуйте копію.

Постійний ключ підпису (щоб оновлюватись поверх) потребує, щоб ви один раз створили ключ і додали його до
секретів репозиторію. Це в «Черзі рішень власника», коли додаток почне використовуватись щодня.

### Що в додатку працює інакше, ніж на сайті
- **Резервна копія й експорт:** замість завантаження файлу відкривається системне вікно «Поділитись»: оберіть
  «Зберегти у Файли / Диск» або надішліть собі.
- **Озвучка:** використовує голоси самого телефона. Якщо голосу для мови немає, додаток це скаже. Додати голос
  можна в налаштуваннях Android (мова й введення → синтез мовлення).
- **Кнопка «Назад»** (не перевірено на телефоні): повертає на попередній екран; з головного закриває додаток.
- Верх екрана відступає від рядка стану, значки рядка стану темні (додаток завжди світлий).

## iPhone: що підготовлено і що потрібно від вас

Проєкт для iPhone (`ios/`) створено, значок і заставка готові. **Зібрати й поставити його на телефон із
Windows неможливо.** Apple вимагає:

| Що | Навіщо |
|---|---|
| **Mac з Xcode** (або платна хмарна збірка на macOS) | зібрати програму |
| **Apple Developer Program, ~$99 на рік** | підписати програму, щоб вона запускалась на справжньому iPhone |

Без платного акаунта Apple програму можна поставити через Xcode на свій iPhone, але вона **перестає працювати
через 7 днів** і її треба ставити знову. Для друзів потрібен TestFlight (теж платний акаунт).

Якщо у вас з'явиться Mac: `npm ci`, `npm run cap:sync`, `npx cap open ios`: відкриється Xcode, далі
вибрати свій iPhone й натиснути ▶. Поки цього немає, користуйтесь на iPhone сайтом-PWA
(`docs/IPHONE_TEST.md`): він стає значком на екрані й працює без інтернету.

**Статус:** проєкт для iPhone **не збирався й не запускався** навіть одного разу: у мене немає Mac. Може
знадобитись правка після першого відкриття в Xcode.

## Для розробника

| Команда | Що робить |
|---|---|
| `npm run cap:sync` | збирає сайт і копіює його в `android/` та `ios/` (разом із плагінами) |
| `npx cap open android` | відкриває проєкт в Android Studio (потрібна Android Studio) |
| `npx cap open ios` | відкриває проєкт у Xcode (лише Mac) |
| `node scripts/make-icons.ts` | заново малює значки й заставки для сайту, Android та iOS |

Код, що відрізняється в додатку, спрямований через `src/ui/native.ts` (`isNativeApp()`): збереження файлів
(`ui/files.ts`), озвучка (`ui/speech.ts`), вимкнення service worker (`ui/pwa.tsx`). Плагіни: Filesystem і Share
(експорт), Text-to-Speech (озвучка).
