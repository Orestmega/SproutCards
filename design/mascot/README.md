# Mascot source pictures

Put the owner's Sprout pictures (generated with Nano Banana from the owner's own description) here:

- `sprout.png` — the main picture, ideally on a plain white background, without the pedestal;
- one picture per mood, the same character with another face: `thinking.png`, `oops.png`,
  `sleepy.png`, `celebrate.png`, `encouraging.png`.

These are source files only; the app uses smaller WebP layers made from them:

```
node scripts/mascot/cut.mjs design/mascot/sprout.png <cut.png> <grid.png>
node scripts/mascot/split.mjs <cut.png> src/assets/mascot <preview.png>
```

`sprout.png` and `sprout-forest.png` were generated by the owner with Nano Banana from the owner's own
description (2026-11-10); see `docs/DATA_SOURCES.md`.
