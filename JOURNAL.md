## Погоджені рішення (від власника, 2026-10-26)

- Продукт: сайт-PWA для карток, встановлюється на телефон; магазини не плануються.
- Стек: TypeScript, React, Vite, IndexedDB (Dexie), Vitest. Python не використовуємо.
- Дані на пристрої, офлайн; акаунти й синхронізація окремим пізнішим етапом.
- Мови навчання: старт EN ↔ UK, структура під будь-які мови.
- Інтерфейс: українська та англійська.
- Режими: картки з перевертанням, Learn (вибір, потім введення), тест, озвучка.
- Дизайн: світла тема, талісман «Sprout» у SVG (оригінальний), великі картки-варіанти.
- Картки: відкриті дані + власні колоди користувача; ШІ-генерація лише пізніше й з позначкою.
- Тестування на пристрої: iPhone власника (через публічну HTTPS-адресу). Симулятор iPhone на Windows недоступний.
- Питання на розуміння не потрібні; власник розбиратиметься в коді після завершення.

**Що зроблено:** `src/core`: `types` (модель даних), `answer` (нормалізація, відстань редагування, «Майже»), `scheduler` (інтерфейс `Scheduler` + фіксовані інтервали 1/3/7/14/30), `learn` (рушій Learn: рівні як дані, обидва напрямки, повернення помилок у чергу через 3–5 карток, підсумок, перетворення в `Progress` і `ReviewLog`), `selection` (відбір карток до повторення і нових), `exchange` (JSON-експорт/імпорт з перевіркою схеми, версіями, новими id), `csv`. `src/db`: схема Dexie v1, репозиторій із транзакціями, налаштування. **Що перевірено (команда, результат):** `npm run test` — 122 тести пройшли (відповіді, планувальник, послідовності Learn, повернення помилок, напрямки, дублікати, порожня колода, одна картка, імпорт/експорт включно з помилковими файлами, збереження після перезапуску БД, оновлення схеми v1→v2 без втрати даних, атомарність транзакцій); `lint`, `typecheck`, `build` — без помилок.
**Не перевірено (зокрема на пристрої):** IndexedDB у справжніх браузерах (лише `fake-indexeddb`); покриття тестами числом не вимірювалось.
**Проблеми й обхідні рішення:** тест знайшов реальну помилку — у резервній копії шляхи помилок для карток і прогресу не мали префікса `decks[i].`; виправлено через префікс у `Collector`.
**Рішення, прийняті самостійно:**
- 2026-10-26. «Майже»: допуск 0 правок для відповідей до 3 літер, 1 для 4–7, 2 для 8+; перестановка сусідніх літер = 1 правка. «Майже» не піднімає рівень і не є помилкою для розкладу. Причина: короткі слова з однією зміненою літерою часто інші слова (cat/car). Альтернатива: єдиний поріг.
- 2026-10-26. Помилка в сесії → рівень −1 і повернення через 3–5 карток; правильна відповідь → картка йде в кінець черги. Розклад призначається один раз, коли картка пройшла сесію: з помилками в сесії = `wrong` (скид до 1 дня), без помилок = `correct`. Незавершена сесія планує лише пройдені картки.
- 2026-10-26. Напрямок сесії міняє боки місцями на всіх рівнях; прогрес зберігається окремо для кожного напрямку.
- 2026-10-26. Якщо для вибору немає хибних варіантів (колода з однієї картки), питання ставиться як введення.
- 2026-10-26. Імпорт завжди створює нові колоди з новими id і нічого не перезаписує; будь-яка помилка в файлі відхиляє весь файл (нічого не пишеться). Прогрес для невідомих карток відкидається з попередженням.
- 2026-10-26. Імпортовані з CSV картки позначаються `reviewed: false`; картки, введені власником вручну, — `reviewed: true`.
