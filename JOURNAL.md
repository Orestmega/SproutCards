## Погоджені рішення (від власника, 2026-10-26)

- Продукт: сайт-PWA для карток, встановлюється на телефон; магазини не плануються.
- Стек: TypeScript, React, Vite, IndexedDB (Dexie), Vitest. Python не використовуємо.
- Дані на пристрої, офлайн; акаунти й синхронізація окремим пізнішим етапом.
- Мови навчання: старт EN ↔ UK, структура під будь-які мови.
- Інтерфейс: українська та англійська.
- Режими: картки з перевертанням, Learn (вибір, потім введення), тест, озвучка.
- Дизайн: світла тема, талісман «Sprout» у SVG (оригінальний), великі картки-варіанти.
- Картки: відкриті дані + власні колоди користувача; ШІ-генерація лише пізніше й з позначкою.
- Тестування на пристрої: iPhone власника (через публічну HTTPS-адресу). Симулятор iPhone на Windows недоступний.
- Питання на розуміння не потрібні; власник розбиратиметься в коді після завершення.

## Рішення, прийняті в ході роботи

(Формат: дата. Рішення. Причина. Альтернатива.)

- 2026-10-26. Файли `CLAUDE (2).md`, `PLAN (1).md`, `JOURNAL (1).md` перейменовано в `CLAUDE.md`, `PLAN.md`, `JOURNAL.md`. Причина: у документах усі посилання на ці назви, а `CLAUDE.md` Claude Code підхоплює автоматично. Альтернатива: лишити як є (посилання були б хибні).
- 2026-10-26. Версії залежностей — найновіші стабільні на момент старту (Vite 8, React 19, TypeScript 7, Vitest 5, ESLint 10, vite-plugin-pwa 2, Dexie 4, react-router 7). Причина: нові проєкти без застарілих версій; `npm install` пройшов без конфліктів peer-залежностей, `npm audit` — 0 вразливостей. Альтернатива: старіші LTS-версії.
- 2026-10-26. Одна `tsconfig.json` (strict, `noUncheckedIndexedAccess`) на весь код, включно зі `scripts/`; `typecheck` = `tsc --noEmit`. Причина: простота. Додано `@types/node` (dev) для скриптів.
- 2026-10-26. Скрипти в `scripts/` пишемо на TypeScript і запускаємо `node scripts/x.ts` (Node 24 виконує TS напряму). Причина: без додаткових залежностей (tsx).
- 2026-10-26. PWA: `registerType: 'prompt'` (оновлення лише після згоди користувача — щоб не перервати навчання й не втратити дані). Тимчасові PNG-іконки згенеровано `scripts/make-icons.ts`.
- 2026-10-26. Локальна git-ідентичність лише для цього репозиторію: `SproutCards Dev <dev@sproutcards.local>` (глобальна не налаштована, глобальні налаштування не чіпаю). Перед push власник вирішує, чия адреса буде в комітах.
